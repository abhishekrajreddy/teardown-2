Drop your screenshots in this folder using these exact filenames so they show up in the main README automatically:

- today.png
- log.png
- supplements.png
- formulary.png
- timeline.png

Easiest way to capture them (mobile-first app, so capture mobile views):
1. Open the app in Chrome, press F12 (DevTools), click the device toolbar icon (or Ctrl+Shift+M / Cmd+Shift+M)
2. Pick "iPhone 14 Pro" or similar from the device dropdown
3. Navigate to each screen, then Ctrl+Shift+P (Cmd+Shift+P on Mac) → type "screenshot" → "Capture screenshot"
4. Save each one into this folder with the filenames above
