Brand & UI direction — v1

Teardown

Every rep tears the fiber down so it rebuilds stronger. The visual language borrows from lab notebooks and exploded-diagram annotation — quiet, dark, precise — so the data reads like evidence, not decoration.

Color palette

Graphite#14151A — page
Charcoal#1D1F26 — surface
Iron#2A2D36 — border
Bone#ECE9E2 — text
Ember#E2853D — accent
Moss#7C9A79 — positive trend

Ember is the only warm, saturated color in the system — used for the one accent action per screen (a CTA, an active nav state, a supplement marker). Moss appears only when a trend is genuinely improving. Everything else stays quiet on purpose.
